# Vue Modal App  

A simple **Vue 3** application with a modal window where users can answer questions.  

## 🚀 Features  
- Open/close modal functionality.  
- Input fields with `v-model`.  
- Data sharing using `provide/inject`.  

## 🔧 Installation & Setup  

```sh
# 1. Clone the repository
git clone https://github.com/YOUR_USERNAME/vue-modal-app.git

# 2. Navigate to the project folder
cd vue-modal-app

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev
